**Django Blog Website**

<h3>A full-featured Blog Web Application built using Django and HTML templates following the Django MVT architecture.
This project simulates a real-world blogging platform where users can read, create, update, and manage blog posts.</h3>

<strong>Features</strong>

<p>User Registration & Login</p>
<p>Create Blog Posts</p>
<p>Edit & Delete Posts</p>
<p>View All Blog Posts</p>
<p>Individual Blog Detail Page</p>
<p>Django Admin Panel</p>
<p>Responsive HTML Templates</p>
<p>Pagination for Blog Posts</p>
<p>Secure Authentication System</p>
<p>Clean URL Structure</p>

<strong>Tech Stack</strong>

<h2>Backend</h2>
<p>Python</p>
<p>Django</p>

<h2>Frontend</h2>
<p>HTML</p>
<p>CSS</p>
<p>Bootstrap</p>

<h2>Database</h2>

<p>SQLite (Default Django DB)</p>
