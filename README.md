<h1>Django Blog Website</h1>

<p>A full-featured Blog Web Application built using Django and HTML templates following the Django MVT architecture.
This project simulates a real-world blogging platform where admin can read, create, update, and manage blog posts.</p>

<h2>Features</h2>

<li>User Registration & Login</li>
<li>Create Blog Posts</li>
<p>Edit & Delete Posts</p>
<p>View All Blog Posts</p>
<p>Individual Blog Detail Page</p>
<p>Django Admin Panel</p>
<p>Responsive HTML Templates</p>
<p>Secure Authentication System</p>
<p>Clean URL Structure</p>

<h1>Tech Stack</h1>

<h2>Backend</h2>
<p>Python</p>
<p>Django</p>

<h2>Frontend</h2>
<p>HTML</p>
<p>CSS</p>
