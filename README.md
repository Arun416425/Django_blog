<h1>Django Blog Website</h1>

<p>A full-featured Blog Web Application built using Django and HTML templates following the Django MVT architecture.</p>
<p>This project simulates a real-world blogging platform where admin can read, create, update, and manage blog posts.</p>

<h2>Features</h2>

<li>User Registration & Login</li>
<li>Create Blog Posts</li>
<li>Edit & Delete Posts</li>
<li>View All Blog Posts</li>
<li>Individual Blog Detail Page</li>
<li>Django Admin Panel</li>
<li>Responsive HTML Templates</li>
<li>Secure Authentication System</li>
<li>Clean URL Structure</li>

<h1>Tech Stack</h1>

<h2>Backend</h2>
<p>Python</p>
<p>Django</p>

<h2>Frontend</h2>
<p>HTML</p>
<p>CSS</p>
<p>Bootstrap</p>

<h2>Database</h2>

<p>SQLite (Default Django DB)</p>
